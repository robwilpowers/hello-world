## Project Hours Ledger

`hours-ledger.html` is the source of a claude.ai artifact for logging weekly hours
against per-project commitments (Mon–Sun grid in 30-minute cells, a year audit view,
and CSV/JSON export). The logged hours live in the artifact's own database, not in
this repo, so opening the file directly shows the layout without saved data.
