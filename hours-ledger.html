Downloads aren't available in this view. Copy the text below into a file instead.

Weeks run Monday to Sunday and are numbered by ISO 8601, so a week belongs to the year that contains its Thursday. Committed hours and the balance count completed weeks only; the current week is shown as in progress. A target applies from the week it starts until a later target replaces it.

Add a project

To end a commitment, add a target of 0 hours from the week it ends. Archiving a project only hides it from the paint palette; its hours and targets stay in the audit. A project can be deleted only while it has no hours logged.
